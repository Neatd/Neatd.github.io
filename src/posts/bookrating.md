# [RecSys] 책 표지와 줄거리까지 학습하면 평점 예측이 더 정확해질까? — 멀티모달 추천 시스템 실험기

> **핵심 주제:** Multimodal Recommendation, Feature Engineering, Wide & Deep, LightGBM, Weighted Ensemble  
>
> **GitHub:** https://github.com/boostcampaitech7/level2-bookratingprediction-recsys-08

## 1. 프로젝트 개요

추천 시스템은 사용자의 과거 행동을 기반으로 사용자가 선호할 만한 아이템을 예측하는 기술이다.

일반적인 추천 시스템에서는 사용자 ID, 아이템 ID, 과거 평점과 같은 정형 데이터를 활용한다. 하지만 책을 추천하는 상황에서는 이러한 정보만으로 사용자의 취향을 충분히 설명하기 어렵다.

예를 들어 같은 장르의 책이라도 어떤 사용자는 표지 디자인에 끌리고, 다른 사용자는 책의 줄거리나 주제를 중요하게 생각할 수 있다.

그렇다면 **책의 메타데이터뿐만 아니라 표지 이미지와 줄거리 텍스트까지 함께 학습하면 평점 예측 성능이 향상될까?**

이 질문에서 프로젝트를 시작했다.

이번 프로젝트의 목표는 사용자와 도서 사이의 상호작용 데이터를 기반으로 평점을 예측하고, 이미지와 텍스트라는 비정형 데이터를 추가하여 추천 성능의 개선 가능성을 검증하는 것이었다.

또한 단순히 복잡한 모델을 사용하는 것이 아니라, 데이터 전처리와 피처 선택, 모델별 학습 특성 분석, 앙상블을 통해 **RMSE(Root Mean Squared Error)를 최소화하는 것**에 집중했다.

## 2. 문제 정의: 데이터가 많아지면 성능도 좋아질까?

### 2.1 정형 데이터만으로는 부족한 사용자 취향

기본적인 도서 평점 예측 데이터는 사용자 정보, 도서 정보, 사용자별 평점으로 구성된다.

| 데이터 | 주요 정보 |
|---|---|
| User | 사용자 ID, 나이, 위치 |
| Book | ISBN, 제목, 작가, 출판사, 출판 연도 |
| Rating | 사용자 ID, ISBN, 평점 |
| Image | 도서 표지 이미지 |
| Text | 도서 줄거리 요약 |

정형 데이터는 추천 모델이 사용자와 도서 사이의 관계를 학습하는 데 유용하다.

하지만 책의 내용이나 표지에서 드러나는 특징을 직접 반영하기 어렵다는 한계가 있다.

이를 보완하기 위해 사전학습된 언어 모델과 이미지 모델을 활용하여 비정형 데이터를 벡터 형태로 변환하는 방법을 검토했다.

### 2.2 멀티모달 데이터의 비용

비정형 데이터를 추가한다고 해서 반드시 성능이 향상되는 것은 아니다.

텍스트와 이미지를 임베딩하면 기존의 범주형 피처보다 훨씬 높은 차원의 특징이 생성된다.

이로 인해 다음 문제가 발생할 수 있다.

- 학습에 필요한 메모리와 연산량 증가
- 모델 복잡도 증가에 따른 과적합 위험
- 실제 평점과 관련이 적은 특징까지 학습할 가능성
- 피처 추출 및 실험 반복에 필요한 시간 증가

따라서 이번 프로젝트에서는 **피처를 얼마나 많이 사용하는가보다, 각 피처가 평점 예측에 얼마나 기여하는가**를 중요한 판단 기준으로 삼았다.

## 3. 멀티모달 피처 엔지니어링

### 3.1 Text: 책의 줄거리를 임베딩으로 표현하기

텍스트 데이터에는 책의 제목과 줄거리 요약 정보가 포함되어 있다.

이러한 자연어 데이터를 추천 모델에 입력하기 위해 사전학습된 Transformer 기반 언어 모델을 활용했다.

실험 대상으로는 BERT, RoBERTa, ELECTRA를 검토했다.

특히 ELECTRA는 BERT와 다른 사전학습 방식을 사용한다는 점에 주목했다.

BERT는 Masked Language Modeling 방식으로 마스킹된 토큰을 예측하지만, ELECTRA는 교체된 토큰이 원래 토큰인지 판별하는 Replaced Token Detection 방식으로 학습한다.

이 방식은 사전학습 과정에서 토큰 단위의 학습 신호를 효율적으로 활용할 수 있다는 장점이 있다.

프로젝트에서는 짧은 실험 기간 내 다양한 텍스트 표현을 비교하기 위해 ELECTRA를 실험 후보로 포함했다.

**텍스트 처리 과정**

1. 책 제목과 줄거리 요약 데이터를 결합한다.
2. 특수문자와 불필요한 공백을 정리한다.
3. 사전학습된 언어 모델을 통해 텍스트를 임베딩한다.
4. 생성한 벡터를 도서 메타데이터와 결합하여 모델 입력 피처로 사용한다.

공개 저장소의 텍스트 전처리 코드에서는 책별 요약 임베딩뿐만 아니라, 사용자가 읽은 책의 정보를 결합하여 사용자 측 텍스트 표현을 생성하는 방식도 확인할 수 있다.

이 접근은 단일 도서에 대한 정보뿐 아니라 사용자의 독서 이력을 텍스트 특징으로 표현할 수 있다는 점에서 의미가 있다.

또한 추출된 임베딩을 저장해 재사용하면 매번 언어 모델을 실행할 필요가 없어 반복 실험 비용을 줄일 수 있다.

### 3.2 Image: 책 표지의 시각적 특징 추출

도서 표지는 색상, 레이아웃, 일러스트 등 다양한 시각적 특징을 포함한다.

이러한 정보가 사용자의 선호도를 설명할 수 있을 것이라는 가설을 세우고 ViT와 ResNet 계열의 이미지 특징 추출 방식을 실험했다.

이미지는 모델 입력에 적합하도록 크기를 통일하고 정규화한 뒤 특징 벡터로 변환했다.

하지만 실험 과정에서 이미지 피처를 추가해도 기대만큼 평점 예측 성능이 개선되지 않는다는 점을 확인했다.

이는 중요한 결과였다.

처음에는 더 많은 정보를 모델에 제공하면 성능이 향상될 것으로 예상했다. 그러나 표지 이미지의 특징이 실제 평점과 강한 관계를 가진다고 보장할 수는 없었다.

책 표지는 장르나 분위기를 간접적으로 표현할 수 있지만, 사용자가 책을 읽은 뒤 부여하는 평점에는 내용, 작가에 대한 선호, 개인적 경험 등 다양한 요인이 작용한다.

따라서 이미지 정보의 예측 기여도가 제한적일 가능성이 있다.

결과적으로 이미지 피처의 효과를 검증하고, 성능 개선 폭에 비해 연산 비용이 크다면 해당 피처를 제외하는 방향을 고려했다.

**이 실험을 통해 얻은 교훈은 멀티모달 데이터를 무조건 추가하는 것이 아니라, 각 모달리티의 실제 기여도를 검증해야 한다는 점이다.**

### 3.3 Feature Selection: 평균 평점은 왜 성능을 떨어뜨렸을까?

피처 엔지니어링 과정에서 인상적이었던 실험 중 하나는 사용자와 도서의 평균 평점을 활용한 파생 피처였다.

직관적으로 생각하면 사용자의 평균 평점은 평점을 높게 주는 성향인지 낮게 주는 성향인지를 설명할 수 있다.

또한 책의 평균 평점은 해당 책에 대한 전반적인 평가를 나타낼 수 있다.

따라서 두 피처 모두 평점 예측에 도움이 될 것으로 예상했다.

그러나 실험에서는 평균 평점 피처를 추가했을 때 학습 데이터와 검증 데이터 사이의 성능 차이가 커지고, 검증 RMSE가 악화되는 현상을 확인했다.

이러한 현상에는 두 가지 가능성이 있었다.

**첫 번째는 과적합(Overfitting)이다.**

모델이 평균 평점에 지나치게 의존하면서 특정 사용자나 책에 대한 학습 데이터의 패턴을 암기할 수 있다.

특히 평점 데이터가 적은 사용자나 도서의 평균은 표본 수가 작기 때문에 안정적인 통계량이라고 보기 어렵다.

**두 번째는 데이터 누수(Data Leakage) 가능성이다.**

평균 평점을 계산할 때 검증 대상의 실제 평점까지 포함하면 모델이 예측해야 할 타깃 정보가 피처에 간접적으로 반영될 수 있다.

다만 학습-검증 성능 차이만으로 누수가 확정되는 것은 아니다. 평균값을 어떤 데이터와 어떤 시점에서 계산했는지 별도로 확인해야 한다.

이러한 점을 고려하여 평균 평점 피처의 효과를 다시 검증했고, 성능에 부정적인 영향을 미치는 피처는 제거했다.

이 경험을 통해 **직관적으로 유용해 보이는 피처라도 실제 검증 성능으로 가치를 판단해야 한다**는 점을 배웠다.

## 4. 모델링: 서로 다른 모델은 어떤 패턴을 학습할까?

단일 모델이 모든 데이터의 특성을 잘 학습하기는 어렵다.

따라서 딥러닝 모델과 트리 기반 머신러닝 모델을 함께 비교했다.

### 4.1 Wide & Deep Network

Wide & Deep Network(WDN)는 선형 모델과 딥러닝 모델을 결합한 구조다.

Wide 부분은 입력 피처의 직접적인 관계를 학습하고, Deep 부분은 임베딩과 다층 퍼셉트론을 통해 복잡한 비선형 패턴을 학습한다.

최종 예측값은 두 부분의 출력을 결합하여 계산한다.

\[
\hat{y} = y_{wide} + y_{deep}
\]

이 구조는 사용자의 과거 상호작용에서 나타나는 명확한 패턴과 일반화가 필요한 복잡한 관계를 함께 반영할 수 있다.

프로젝트에서는 WDN을 활용하여 사용자와 도서 간의 상호작용을 학습하고, 다른 모델과의 예측 차이를 비교했다.

또한 DeepFM 등 다른 추천 모델을 실험하여 피처 상호작용을 학습하는 방식의 차이가 예측 성능에 어떤 영향을 주는지 확인했다.

### 4.2 LightGBM과 CatBoost

딥러닝 모델과 별개로 LightGBM, CatBoost와 같은 Gradient Boosting 기반 트리 모델도 활용했다.

트리 기반 모델은 정형 데이터의 비선형 관계와 피처 간 상호작용을 학습하는 데 강점이 있다.

특히 LightGBM은 효율적인 학습 구조를 기반으로 다양한 피처 조합을 빠르게 실험할 수 있다는 장점이 있다.

반면 딥러닝 모델은 임베딩을 통해 사용자와 아이템의 잠재적인 관계를 표현할 수 있다.

이처럼 서로 다른 모델은 동일한 데이터에서도 다른 패턴을 학습할 수 있다.

따라서 어느 하나의 모델만 사용하는 것보다, 모델별 예측 결과를 결합하면 일반화 성능을 개선할 가능성이 있다고 판단했다.

## 5. Weighted Ensemble: 서로 다른 예측을 결합하기

### 5.1 왜 앙상블을 선택했을까?

모델을 비교하면서 중요하게 생각한 점은 개별 모델의 성능뿐 아니라 **모델 간 예측 오차의 차이**였다.

두 모델이 비슷한 RMSE를 기록하더라도 서로 다른 샘플에서 오류를 발생시킨다면, 예측값을 결합했을 때 전체 오차가 줄어들 수 있다.

이번 프로젝트에서는 WDN과 LightGBM의 학습 특성이 다르다는 점에 주목하여 가중 앙상블을 활용했다.

WDN은 임베딩 기반의 복잡한 사용자-도서 상호작용을 학습하는 데 강점이 있고, LightGBM은 정형 피처의 분기 패턴을 효율적으로 학습할 수 있다.

따라서 두 모델의 예측을 결합하는 방식으로 단일 모델의 한계를 보완하고자 했다.

### 5.2 K-Fold OOF 기반 가중치 검증

앙상블 가중치를 안정적으로 결정하기 위해 K-Fold Out-of-Fold(OOF) 예측을 활용했다.

OOF는 각 Fold에서 해당 검증 샘플을 학습하지 않은 모델로 예측값을 생성하는 방법이다.

이를 통해 학습 데이터 전체에 대한 검증용 예측값을 확보하고, 앙상블 가중치에 따른 성능 변화를 비교할 수 있다.

Weighted Ensemble은 다음과 같이 표현할 수 있다.

\[
\hat{y}_{ensemble}
= \alpha\hat{y}_{LGBM}
+ (1-\alpha)\hat{y}_{WDN}
\]

여기서 \(\alpha\)는 LightGBM에 부여하는 가중치이며, 두 모델의 가중치 합은 1이 되도록 설정한다.

가중치를 바꿔가며 RMSE를 비교해 가장 적합한 조합을 탐색했다.

공개 저장소에도 여러 모델의 예측 CSV를 입력받아 동일 가중 평균 또는 사용자 지정 가중 평균을 계산하는 앙상블 구현이 포함되어 있다.

이를 통해 모델별 학습 과정과 최종 예측 결합 과정을 분리할 수 있었다.

### 5.3 앙상블이 효과적인 조건

앙상블의 핵심은 모델 수를 늘리는 것이 아니다.

서로 다른 모델이 얼마나 상호보완적인 예측을 생성하는지가 중요하다.

예를 들어 LightGBM과 WDN이 항상 유사한 예측을 한다면 결합하더라도 성능 개선은 크지 않을 수 있다.

반대로 특정 사용자나 도서에서 한 모델의 오차를 다른 모델이 보완한다면 앙상블 효과를 기대할 수 있다.

이번 실험에서는 모델별 RMSE와 예측 분포를 비교하고, 가중치 조합에 따른 성능 변화를 확인하면서 앙상블 전략을 결정했다.

## 6. 실험 결과 분석

모든 실험은 RMSE를 중심으로 평가했다.

RMSE는 예측값과 실제 평점 사이의 차이를 제곱한 뒤 평균을 구하고 제곱근을 취한 지표다.

\[
RMSE = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(y_i-\hat{y}_i)^2}
\]

제곱 오차를 기반으로 계산하므로 큰 예측 오류에 상대적으로 민감하며, 값이 낮을수록 예측 성능이 좋다.

실험 결과를 분석할 때는 단순히 최종 RMSE뿐 아니라 학습-검증 성능 차이와 예측값 분포도 함께 살펴봤다.

Plotly를 활용하여 예측값의 분포를 확인하고, 일부 구간에서 예측값이 과도하게 집중되거나 비정상적인 값이 발생하는지도 검토했다.

주요 실험에서 얻은 결과를 정리하면 다음과 같다.

| 실험 | 관찰 결과 | 의사결정 |
|---|---|---|
| 텍스트 임베딩 | 줄거리 정보 활용 가능성 확인 | 효율적인 임베딩 방식 비교 |
| 이미지 임베딩 | 기대 대비 제한적인 성능 기여 | 비용 대비 효과 검토 |
| 평균 평점 피처 | 검증 성능 악화 및 과적합 징후 | 성능 저해 피처 제거 |
| WDN / DeepFM | 비선형 상호작용 학습 특성 비교 | 딥러닝 모델 후보 선정 |
| LightGBM / CatBoost | 정형 데이터 기반 학습 성능 비교 | 트리 모델 활용 |
| Weighted Ensemble | 단일 모델 대비 성능 개선 확인 | 최종 예측 결합 전략 채택 |

최종적으로는 WDN과 LightGBM의 예측값을 결합하는 방식이 효과적이라는 결론을 얻었다.

다만 이러한 결과가 모든 추천 시스템에서 동일하게 나타나는 것은 아니다. 데이터의 특성, 모델의 학습 방식, 검증 환경에 따라 멀티모달 피처와 앙상블의 효과는 달라질 수 있다.

## 7. 프로젝트를 통해 배운 점

### 7.1 좋은 피처는 복잡한 피처가 아니다

처음에는 이미지나 텍스트처럼 풍부한 정보를 추가하면 모델 성능도 자연스럽게 향상될 것이라고 생각했다.

그러나 이미지 실험에서 확인했듯이 정보량이 많다고 해서 반드시 예측에 유용한 것은 아니었다.

모델에 추가하는 정보가 실제 타깃과 얼마나 관련되어 있는지 검증하는 과정이 중요했다.

### 7.2 성능 저하의 원인도 중요한 실험 결과다

평균 평점 피처는 직관적으로 유용해 보였지만 실제 실험에서는 검증 성능을 악화시켰다.

이를 단순히 실패한 실험으로 넘기기보다 과적합 가능성과 피처 생성 과정의 데이터 누수 위험을 검토했다.

이 과정에서 피처 생성 방식과 검증 데이터 분리의 중요성을 더 명확하게 이해할 수 있었다.

### 7.3 모델의 다양성이 앙상블 성능을 결정한다

앙상블을 통해 배운 점은 단순히 성능이 좋은 모델들을 평균내는 것만으로는 충분하지 않다는 사실이다.

각 모델이 어떤 특징을 학습하고, 어떤 데이터에서 오류를 발생시키는지 이해해야 효과적인 결합이 가능하다.

WDN과 LightGBM은 서로 다른 구조를 가지고 있기 때문에 예측 결과를 결합하여 단일 모델의 한계를 보완할 수 있었다.

## 8. 마무리

이번 프로젝트는 단순히 다양한 추천 알고리즘을 적용하는 것을 넘어, **데이터의 특성에 따라 어떤 정보를 활용하고 어떤 모델을 선택해야 하는지 실험적으로 판단한 경험**이었다.

특히 세 가지가 기억에 남는다.

첫째, 멀티모달 정보가 항상 성능 개선으로 이어지는 것은 아니며, 실제 기여도를 기준으로 활용 여부를 결정해야 한다.

둘째, 피처 엔지니어링에서는 새로운 특징을 추가하는 것뿐 아니라 성능을 저해하는 특징을 제거하는 과정도 중요하다.

셋째, 서로 다른 학습 특성을 가진 모델을 적절하게 결합하면 단일 모델보다 안정적인 예측을 기대할 수 있다.

결국 추천 시스템의 성능은 모델의 복잡도만으로 결정되지 않는다.

**데이터를 이해하고, 가설을 세우고, 실험 결과를 근거로 불필요한 요소를 제거하며 모델을 개선하는 과정이 핵심**이라는 점을 배울 수 있었다.
