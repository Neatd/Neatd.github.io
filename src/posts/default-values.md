## 0도 유효한 값일 때

수량이 없는 항목에는 기본 수량을 넣되, 사용자가 선택한 `0`은 유지해야 한다고 가정해봅시다.

```javascript
const quantity = 0;

console.log(quantity || 1); // 1
console.log(quantity ?? 1); // 0
```

`||`는 왼쪽 값이 거짓으로 평가되면 오른쪽 값을 사용합니다. 반면 `??`는 왼쪽 값이 `null` 또는 `undefined`일 때만 오른쪽 값을 사용합니다.

## 입력을 나란히 비교하기

| 입력 | `value || '기본값'` | `value ?? '기본값'` |
| --- | --- | --- |
| `0` | `'기본값'` | `0` |
| `''` | `'기본값'` | `''` |
| `false` | `'기본값'` | `false` |
| `null` | `'기본값'` | `'기본값'` |
| `undefined` | `'기본값'` | `'기본값'` |

어느 연산자가 항상 더 좋다고 정할 수는 없습니다. 빈 문자열도 기본값으로 대체할지, 비어 있다는 사용자의 선택으로 보존할지가 먼저 정해져야 합니다.

## 규칙을 먼저 설명하기

> "값이 없으면 기본값을 쓴다"에서, 값이 없다는 조건을 먼저 구체적으로 정합니다.

코드를 수정한 뒤에는 일반 입력뿐 아니라 `0`, 빈 문자열, 누락된 값도 함께 확인합니다. 작은 경계값이 의도와 구현의 차이를 드러내기도 합니다.
